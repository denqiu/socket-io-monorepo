<h1>util-eslint</h1>
<ul>
    <li>src folder: Manages linting rules.</li>
    <li>lint-helper.js: Assists linting process.</li>
    <li>rules-generate-demo.js: Automatically generates demo code from a rule's test cases.</li>
    <li>rules folder: Manage rules that can be imported for any codebase.</li>
    <li>custom-rules folder: Manage rules designed specifically for this codebase.</li>
</ul>
